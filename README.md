# Ja releases

This repository holds only the signed release APKs of Ja, a personal Android app by Chidocuate. The source code lives in a private repository.

## Install

1. Install Obtainium from https://github.com/ImranR98/Obtainium/releases.
2. In Obtainium, add `https://github.com/chidocuate/ja-releases` as an app source.
3. Obtainium installs the arm64-v8a APK and updates it when a new release appears.

Each release has `ja-<version>-arm64-v8a.apk` for phones and tablets, `ja-<version>-universal.apk` for emulators, and `SHA256SUMS.txt`.
